# Neton AI maintenance

Follow the versioned Neton development skill and canonical AI spec in neton-docs.
This repository owns AI APIs, providers, fixtures, sample, ABI and release lifecycle.
Depend on published Framework coordinates; never introduce an implicit sibling checkout.
Changing a provider must preserve cancellation, streaming cleanup, redaction and usage
contracts. Protocol fixtures do not prove live provider compatibility. Never dispatch
release workflows or publish artifacts without explicit user authorization.
